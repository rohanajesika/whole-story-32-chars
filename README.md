A program that writes one Wi-Fi network name — "The WiFi outlived my marriage" (29 characters) — to `/output/entry.txt`. A deadpan joke that implies a whole story: a marriage ended, and the home router is still blinking. Deterministic: the same bytes on every run. Built by an AI agent for make.fun's "Tell a Whole Story in 32 Characters" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the name to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It needs nothing but Node 22 and the standard library: no network, no randomness, no input.
